# 마법의 엘리베이터

## 1. 생각 방식

현재 층의 **일의 자리부터 하나씩 처리**했다.

```java
int x = storey % 10;
```

현재 숫자가 `5`보다 작으면 내려가는 게 더 적게 누른다.

```java
if(x < 5){
    answer += x;
}
```

예를 들어 `3`이면

```text
3 → 0 : 3번
3 → 10 : 7번
```

이므로 내려간다.

반대로 `5`보다 크면 위로 올려서 `10`을 만드는 게 더 적게 누른다.

```java
answer += 10 - x;
storey += 10;
```

`storey += 10`을 해서 다음 자리로 올림을 넘긴다.

### 일의 자리가 5인 경우

`5`는 위로 가도 5번, 아래로 가도 5번이라서 **다음 자리 숫자를 확인해야 한다.**

```java
if(y % 10 >= 5){
    storey += 10;
}
```

다음 자리도 `5 이상`이면 올림을 해주는 게 이후 계산에서 더 유리하고, `5 미만`이면 그냥 내려간다.

한 자리를 처리한 뒤

```java
storey = storey / 10;
```

해서 다음 자리로 넘어간다.

---

## 2. 자료구조 선택 이유

따로 자료구조는 필요하지 않았다.

현재 숫자의 일의 자리만 확인하면서 바로 처리할 수 있어서 숫자 연산만 사용했다.

---

## 4. 시간복잡도

한 번 반복할 때마다

```java
storey /= 10;
```

으로 자릿수가 하나씩 줄어든다.

`storey`의 자릿수를 `D`라고 하면 시간복잡도는

```text
O(D)
```

이다.

---

## 5. 코드 피드백

현재 코드에서 핵심인

```java
if(x < 5)
else if(x == 5)
else
```

구조는 그대로 가져가면 된다.

특히 `x == 5`일 때 다음 자리까지 보는 부분이 이 문제에서 중요한 부분이다.

```java
int y = storey / 10;

if(y % 10 >= 5){
    storey += 10;
}
```

`while(true)`에서 내부에 `break`를 두는 것보다

```java
while(storey > 0)
```

으로 바로 조건을 적으면 조금 더 단순하다.

그리고 마지막

```java
else if(x > 5)
```

는 앞에서 `< 5`, `== 5`를 확인했기 때문에 그냥 `else`로 써도 된다.

### 정리한 전체 코드

```java
class Solution {
    public int solution(int storey) {

        int answer = 0;

        while(storey > 0){

            int x = storey % 10;
            int y = storey / 10;

            if(x < 5){
                answer += x;

            }else if(x == 5){

                answer += 5;

                if(y % 10 >= 5){
                    storey += 10;
                }

            }else{
                answer += 10 - x;
                storey += 10;
            }

            storey /= 10;
        }

        return answer;
    }
}
```

이 문제는 **일의 자리부터 그리디하게 처리하되, `5`일 때만 다음 자리를 확인한다**가 핵심이다.
