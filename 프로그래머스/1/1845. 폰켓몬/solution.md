# 1845. 폰켓몬

## 1. 생각 방식

먼저 전체 폰켓몬 수를 `num`에 저장하고, 가져갈 수 있는 개수를 `x = num / 2`로 구했다.

그다음 `HashSet`에 `nums`의 값을 전부 넣어서 중복을 제거하고 폰켓몬 종류 수를 구했다.

종류 수가 `x`보다 많거나 같으면 어차피 `x`마리만 가져갈 수 있으니까 `x`를 반환하고, 종류 수가 더 적으면 `set.size()`를 반환했다.

## 2. 자료구조 선택 이유

폰켓몬 번호의 중복을 제거해서 종류가 몇 개인지만 확인하면 되기 때문에 `HashSet`을 사용했다.

## 3. 시간복잡도

`nums`를 한 번 순회하면서 `HashSet`에 값을 넣으므로 평균 시간복잡도는 `O(N)`이다.
